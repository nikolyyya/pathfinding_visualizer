# Визуализация алгоритмов поиска пути

Программа показывает работу BFS, алгоритма Дейкстры и A* на сетке 24 × 36. Соседними считаются клетки, у которых есть общая сторона. Вход в обычную клетку стоит 1, во взвешенную — 5.

## Запуск

Из папки проекта в Ubuntu можно запустить программу через готовое окружение.

```bash
./venv/bin/python main.py
```

Если окружения ещё нет, установите зависимости и запустите программу.

```bash
python3 -m venv venv
./venv/bin/python -m pip install -r requirements.txt
./venv/bin/python main.py
```

## Управление

| Действие | Управление |
| --- | --- |
| Поставить стену | ЛКМ |
| Удалить стену или вес | ПКМ |
| Перенести старт или цель | S или G + ЛКМ |
| Поставить вес 5 | W + ЛКМ |
| Выбрать алгоритм | 1 — BFS, 2 — Dijkstra, 3 — A* |
| Запустить или поставить на паузу | Пробел |
| Выполнить один шаг в паузе | N |
| Сбросить результат | R |
| Очистить карту и вернуть старт и цель на исходные места | C |
| Увеличить или уменьшить скорость | ↑ / ↓ |
| Закрыть окно | Esc |

Длина пути — число переходов между клетками. Стоимость считается по клеткам маршрута после старта. BFS выбирает путь по числу переходов, Дейкстра и A* учитывают стоимость клеток. Чтобы сравнить алгоритмы, поставьте несколько весов между стартом и целью, запустите BFS, затем переключитесь на Дейкстру или A* и повторите поиск на той же карте.
